## Live-service and data requirements

The personal database connection is not present in this checkout. Connected accounts did not reveal an identifiable active StaxNYC database or a matching Vercel project. The user's deployed URL has been requested. Production authentication, RLS/column permissions, profile defaults, realtime publication, email redirects/delivery, and the external sports/highlight sync jobs still need to be checked against that deployment.

The supplied repository contains no 2023–24 training dataset, fitted model artifact, verified prediction-accuracy report, or scheduled ingestion implementation. The code does not claim those assets or fabricate a confidence score. The new per-player model requires at least 20 completed valid logs and explicitly states its inputs, validation sample size, baseline comparison and uncertainty limitations.

The original team SQL/backend infrastructure was separately managed and is not silently recreated or applied to production. Missing extension tables produce visible unavailable/fallback states. No production account, database or message writes were performed during verification.
